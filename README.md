One line. One out-of-office auto-reply. The funniest I could write in 140
characters or fewer.

## The line

> I'm currently out of the office and have delegated all decisions to a houseplant named Gary, who is doing great.

112 characters, single line, no link, no second line.

## How it was chosen

Five candidate lines were written first (specificity is the engine: a named
houseplant beats a generic "I'm away"), then judged pairwise against the
judge's own brief — a real reply a person would actually set, a genuine
surprise, a voice of its own, freshness, and not one wasted word — each pair
judged twice with the order swapped. Gary won every pairing. A humanizer pass
then stripped anything that sounded written by a template.

## Run it

`main.ts` (Node 22) writes the line to `/output/entry.txt`.

```sh
node main.ts
cat /output/entry.txt
```
